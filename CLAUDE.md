# jboursiquot.com

Personal site, built with Hugo and hosted on Netlify. The page is aimed at potential employers: a LinkedIn-style profile with a skill map of past roles.

## Deploy

- Every push to `master` deploys to production. The Netlify GitHub app builds the commit and publishes it to https://www.jboursiquot.com (the apex domain 301s to `www`). No CI or deploy config lives in this repo.
- Build settings (command, Hugo version, publish dir) are set in the Netlify UI; there is no `netlify.toml`. The live build has reported `Hugo 0.85.0` with minified output, so the command is probably `hugo --minify`. Keep `config.toml` compatible with that old version (for example, `languageCode` stays even though newer Hugo prefers `locale`).
- DNS: Route 53 (AWS nameservers). `www` is a CNAME to `jboursiquot.netlify.com`.
- To verify a deploy, `curl -s https://www.jboursiquot.com/ | grep -c '<new text>'` should be nonzero within a minute or two of the push.

## Where to edit

- Never hand-edit `layouts/index.html`, `static/llms.txt`, or `static/index.md`. They are generated by `python3 site/build.py` (run from the repo root; no dependencies beyond Python 3). Commit the generated files with the source change.
- `site/data/profile.json` holds everything about the person: summary, About paragraphs, experience (roles, durations, bullets), the skill map, capabilities, stack, photos, recent work, and repos. Skill-map links carry an `inferred` list for links not stated in the résumé.
- `site/data/engagements.json` is the public talks/workshops/podcasts archive, newest first.
- `site/site.css` and `site/site.js` are inlined into the page by the build. `site/build.py` holds the markup.
- Photos served by the page live in `static/img/` and are referenced as `img/<file>`. Crop and resize before adding (roughly 1200 to 1600px on the long edge). Crop out any on-screen caption text.
- `static/images/collage.jpg` is embedded by `README.md`, and `static/images/boursiquot-johnny-small.jpg` is the old headshot URL; keep both.
- `README.md` is the GitHub **profile** README (the repo is `jboursiquot/jboursiquot`). It does not feed the website and needs separate updates.
- Contact is LinkedIn only. Do not put an email address anywhere on the site, in the JSON-LD, or in the LLM files.

## LLM-friendly files

- `static/llms.txt` follows llmstxt.org; `static/index.md` is the whole profile as Markdown. The page links both with `<link rel="alternate" type="text/markdown">` and carries schema.org JSON-LD.

## Local preview

`python3 site/build.py && hugo server`, then open http://localhost:1313. `public/` is the git-ignored build output.
